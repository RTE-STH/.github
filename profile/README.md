# 👷‍♂️ Services et Travaux Héliportés — Organisation GitHub

Bienvenue dans l’organisation GitHub dédiée aux projets du service **Services et Travaux Héliportés** de **RTE (Réseau de Transport d’Électricité)**.

## 🎯 Objectif

Cette organisation centralise les projets techniques, outils et expérimentations développés dans le cadre des activités héliportées, notamment :

* Skylink
* Macro Lidar
* Développement d’outils internes divers (scripts, automatisations, applications)
* ...

## 🔐 Accès et confidentialité

⚠️ Cette organisation est réservée à un usage **professionnel interne**.
Certains dépôts peuvent contenir des informations sensibles ou stratégiques.

Merci de :

* Respecter les règles de sécurité informatique
* Ne pas partager de données en dehors des canaux autorisés
* Utiliser des dépôts privés uniquement

## 🤝 Bonnes pratiques

* Rédiger des README clairs pour chaque projet
* Documenter le code et les choix techniques
* Utiliser des branches et des pull requests pour les évolutions
